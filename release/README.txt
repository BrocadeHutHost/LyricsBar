LyricsBar 1.0.0  (Windows 10 / 11 x64)
=====================================

极低内存的本地音乐播放器。免安装、免运行库，双击 LyricsBar.exe 即可。

【快速开始】
1. 双击 LyricsBar.exe 或 启动播放器.bat
2. 默认扫描 音乐 文件夹（C:\Users\<用户名>\Music）
3. 点主界面右上角「文件夹」切换任意音乐目录

【常用操作】
- 曲目库：查看全部曲目，单击播放，滚轮翻页
- 右侧 × ：收进托盘，音乐继续播放
- 托盘图标：单击恢复主界面，右键播放控制 / 退出
- Ctrl + Alt + Q：退出程序
- 歌词条滚轮：音量；Shift + 滚轮：透明度；双击：打开主界面

【配置与缓存】
LyricsBar.ini   配置（音量、循环模式、上次播放位置、播放源）
Lyrics\         歌词缓存
Covers\         专辑封面缓存

删除以上目录不影响程序运行，只会重新生成。

【性能】
后台播放工作集约 5 MB，CPU 占用 < 1%，单文件约 0.5 MB。

【说明】
歌词与封面来自公开搜索接口，仅用于个人学习与本地播放。
