## 本版内容

- 原生 C++ / Win32 / GDI，2 倍超采样 + 双缓冲，无闪烁、无锯齿。
- 曲目库：播放源分组、单击切歌、滚轮翻页、当前曲目高亮。
- 播放源切换：切到某文件夹后，播放与上一首/下一首都限定在该文件夹。
- 悬浮歌词条：悬停浮出半透明控制条（暂停 / 上一首 / 下一首 / 音量），可拖动。
- 圆盘专辑封面自动匹配，CPU 双线性旋转 + 圆形羽化。
- 歌词缺失自动补全，缓存到 `Lyrics\`。
- 续播记忆：退出或每 8 秒记录曲目与进度，启动时恢复。
- 托盘常驻、单实例、四种循环模式。
- 自绘文件夹选择框，不依赖 `shell32`。
- 自检自愈：卡死重开、文件缺失跳过、空歌单重扫、工作集回收。

## 实测性能（Windows 11 x64）

| 场景 | 工作集 | 私有内存 | CPU |
|---|---|---|---|
| 后台播放 | 3.8–5.8 MB | 9.4–9.9 MB | < 1% |
| 前台 + 曲目库 | 约 28 MB（瞬时，含 2 倍缓冲） | — | < 2% |

后台常驻内存约为常见桌面音乐客户端（100–300 MB）的 **1/20 – 1/60**。
