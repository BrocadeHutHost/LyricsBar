## 制作方式

1. 用 `PrintWindow` 抓取真实运行界面（主界面、曲目库、文件夹选择框），歌词条用屏幕抓取。
2. 以目录中的《暖暖》实际播放，主界面、曲目库均处于该曲目状态。
3. 旁白用 edge-tts 逐段合成，按实测时长排时间轴，再与《暖暖》片段混音。
4. 画面用 Pillow 逐帧合成（渐变背景、卡片阴影、柱状图动画、文字动效），通过管道送入 ffmpeg 编码 H.264 + AAC。
